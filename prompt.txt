在现有 subtitle 骨架上，把它做成一个能正确处理时间轴与断句的字幕工具。保留 Cue、parse_time、
format_time、parse_srt、shift、fix_overlaps、split_long、write_srt 的现有名字与签名，只用 Python
标准库，不得引入第三方依赖，不得改动 data/demo.srt。

## 需要完成

1. **时间戳**
   - 逗号与点号分隔都要正确解析，毫秒不能丢。
   - 负偏移后不能出现负时间。
   - 支持 23.976 与 25 帧之间的换算，换算规则写进 README。

2. **重叠**
   - 真正重叠的条目要修正，原本不相接的条目之间的间隙要保留。
   - 修正后每条时长不能小于一个下限。

3. **断句**
   - 中英混排不能切断英文单词，也不能把中文词组拆散。
   - 每行有宽度上限，超过上限要继续拆，拆分结果满足上限。
   - 拆分后的时间要与文本长度成比例。

4. **输出**
   - 序号连续，时间格式合法，读回后条目数与原条目对应关系一致。
   - 连续跑两次逐字节相同。

5. **测试**
   - 覆盖：逗号解析、负偏移钳制、间隙保留、英文不断词、行宽上限、两次输出一致。
   - `python -m pytest tests -q` 全部通过。

完成后跑一遍 `python -m subtitle.cli data/demo.srt --shift-ms 0 --max-chars 18 --out out.srt`，把输入
5 条拆成多少条、每条的行宽、重叠修正前后的时间差贴进 README。
